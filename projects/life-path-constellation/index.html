Life Path Constellation

A 10-year life plan turned into a game you actually reopen.

View live demo

The problem

A five-pillar life plan (spirituality, career, finance, relationships, health) mapped across now/5-year/10-year horizons existed only as a static written doc — easy to draft once and easy to never open again.

Approach

  1. Modeled each pillar as a branch of a radial 'skill tree' / constellation, with three time-horizon stars per branch radiating out from a central 'you are here' hub.
  2. Applied a colorblind-safe, contrast-validated categorical color system — checked with a validator script rather than eyeballed — so each pillar reads as a distinct identity in both the visual map and a plain-text accessible table view.
  3. Built a client-side goal-tracking layer: checkboxes, custom goal entry, per-star progress rings, and an overall progress bar.
  4. Replaced browser storage with an explicit save/load file, so progress is portable across devices and never silently disappears.
  5. QA'd every state — desktop, mobile, post-interaction, save/load round-trip — with headless-browser screenshot testing before calling it done.

Solution

A single self-contained HTML file that opens instantly with no install or server: an interactive constellation map (or a plain accessible table, toggled with one click) where goals can be checked off, new ones added per pillar, and progress exported to and restored from a small JSON file.

Impact

33+ Goals tracked across 5 pillars × 3 time horizons, plus unlimited user-added goals
1 file, 0 dependencies Footprint fully portable — opens in any modern browser
CVD-validated palette + non-visual table view Accessibility colorblind-safe categorical colors, checked with a validator rather than eyeballed

What I'd carry forward

Building under a strict no-browser-storage constraint initially felt like a limitation — it ended up being the better design for a personal tool meant to be reopened across devices: an exportable save file is more trustworthy than invisible local state that can quietly reset.
